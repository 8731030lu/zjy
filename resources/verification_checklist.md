# 译文核验清单（四类问题）

翻译完成后逐项自检，结果写入 `/app/output/verification.md`。发现问题先修正译文，再记录到核验报告。

## 1. 术语稳（terminology）

- [ ] 术语表每个源词只有一条锁定译名。
- [ ] 在标题、摘要、正文、图注、结论五处检索，译名完全一致。
- [ ] 无临时改译、无同义词混用、无"保留原文"与"译名"并存。
- [ ] 缩写与全称译名一致；首次出现处格式正确。

## 2. 段落全（paragraph）

- [ ] `para_id` 总数与原文段落数一致。
- [ ] `para_id` 顺序与原文阅读顺序一致（含跨页、跨栏、跨章节）。
- [ ] 无漏段（尤其页边界、栏切换、图/表插入处）。
- [ ] 无重复翻译、无两段并一段、无一段拆两段。

## 3. 关系准（relation）

- [ ] **数字/单位**：数值、量纲、误差、范围原样；无换算、无四舍五入。
- [ ] **公式**：公式内容与编号保留；只译周围文字。
- [ ] **图表编号**：Fig./Table/Eq. 编号与原文一致。
- [ ] **文献编号/引用**：`[n]`、`(Author, year)` 原样保留，不译不改写。
- [ ] **否定与限定**：not/only/unless/at least/at most/≤/≥/approximately/exactly/except 未丢失、未反转。
- [ ] **指代**：this/it/former/latter/which 指代明确，或已译为显式名词。
- [ ] **因果与让步**：because/although/however/therefore/despite 逻辑关系保留。

## 4. 可核验（verifiability）

- [ ] 每段译文有原文定位（页码/段落/图表/字段/公式位置）。
- [ ] 译不准处显式标注（【未译】/【待确认】/【OCR 存疑】），不混入正文。
- [ ] 未报告、无法判断、材料冲突处单独列出，不写成事实。

## 核验报告格式（verification.md）

```markdown
# 核验报告
- 检查项：terminology / paragraph / relation / verifiability
- 术语一致率：n/m（发现的不一致已修正）
- 段落完整：para_id 总数、顺序核对结果
- 关系准确：抽查 + 模式扫描结果
- 待人工确认清单：
  1. …（位置、原因）
- 未报告/无法判断清单：
  1. …
```
