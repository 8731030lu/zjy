# 译文核验清单（四查）

译完逐项核对，结果写入 `/app/output/verification.md`。发现错误就地修正；无法判定者列入 `result.json.uncertainty`，不写成事实。

## 一查：术语稳
- [ ] 同一术语在标题 / 摘要 / 正文 / 图注 / 结论译名一致（抽查 5 处以上）。
- [ ] 术语表无空译名、无同一源词多译名（除非 note 注明"待人工确认"且正文只用其一）。
- [ ] 缩写首现处给了全称 + 缩写，之后仅用缩写。
- [ ] 翻译中未出现"临时改译"（与术语表不一致的译法）。

## 二查：段落全
- [ ] `bilingual.md` 的 `para_id` 数量与顺序 = `source.json`。
- [ ] 无漏段、无重段、无错位。
- [ ] 跨页 / 跨栏 / 跨章节续段已合并，页码与接续标注正确。
- [ ] 图注、表头、公式块、文献条目均已覆盖（不因"小段"被忽略）。

## 三查：关系准
- [ ] 数字：数值、精度、小数点、负号原样；不换算、不四舍五入。
- [ ] 单位：量纲、±、~、≤、≥、×、^ 等符号原样。
- [ ] 公式：内容与编号保留，只译周围文字。
- [ ] 编号：文献 `[n]`、图 `Fig. n`、表 `Table n`、公式 `Eq. (n)` 原样。
- [ ] 否定与限定：not / only / unless / at least / no / without / approximately 不丢、不反。
- [ ] 指代：this / it / former / latter 指代不明处已译成显式名词。
- [ ] 因果与让步：because / due to / although / despite / whereas 关系保留。

## 四查：可核验
- [ ] 每段译文有 `page` / `section` / `para_id`（必要时 `sentence`）定位。
- [ ] 每个关键结论（术语译法、数字/公式/引用、存疑项）在 `evidence` 中有条目。
- [ ] 未译、存疑、OCR 存疑处已用 `【未译】/【待确认】/【OCR 存疑】` 显式标注，并列入 `uncertainty`。

## 核验报告模板（verification.md）

```markdown
# 核验报告
- case_id: …
- 术语稳: 通过 / 发现 N 处并修正
- 段落全: para_id 总数 = …，与原文一致 / 有缺失（列出）
- 关系准: 数字/单位/公式/编号/否定/指代 逐项结果
- 可核验: 证据条数 = …，存疑项 = …
- 待人工确认: …（列出，与 result.json.uncertainty 一致）
```
