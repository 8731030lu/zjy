# 异常处理手册

遇到下列情况时，保存已得到的部分产物，并在 `result.json` 的 `status`/`uncertainty`/`change_log` 中如实说明。不编造原文没有的内容。

## 文字层缺失 / 扫描件
- 用可用的 OCR 方式识别；识别质量差的段落标注 `【OCR 存疑】`，并保留原文，避免误译。
- 整篇无法识别 → `status: refused`，写清"文字层缺失且 OCR 不可用"。

## 公式 / 表格为图片
- 公式为图片：保留图片，标注"图内公式未译"；只译公式编号与周围文字。
- 表格为图片：尽量按行列转写；无法可靠转写则保留图片并标注"表格未译"。
- 不要凭视觉猜测公式内容或数值。

## 参考文献无法解析
- 保留原文条目原样，不猜测补全作者/年份/页码。
- 正文文献编号 `[n]` 原样保留。

## 原文残缺 / 截断
- 明确标注缺失范围（页码/段落），给 `status: partial` 并写清限制。
- 不补写缺失内容。

## 语言混杂
- 混有非目标语言段落：说明处理策略（保留/翻译）并保持一致。
- 无法判断处标注 `【待确认】`。

## 术语歧义 / 多义
- 一个源词多个可能译名：锁定一个主译名，其余候选写入术语表备注，标注"待人工确认"。
- 不混用两个译名。

## 材料缺失 / 无法判断
- 材料文件不存在或不可读 → `status: refused` + 原因，报告可人工接管位置。
- 无法判断 → `status: cannot_judge` + 原因；不写成事实。

## 运行预算
- 预算：64 次模型请求、900 秒、单响应含推理 ≤16384 token。
- 优先完成"全文段落 → 术语表 → 逐段翻译"主链路，核验从数字/单位/公式/引用/否定做起。
- 每完成一个阶段就写盘，失败时仍有部分产物可交。
