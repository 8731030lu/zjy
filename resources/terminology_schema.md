# 术语表格式与锁定规则

## 目的
保证同一术语在标题、摘要、正文、图注、结论中**始终使用同一译名**，术语表是"被执行"的约束，不是写在提示里的口号。

## 文件格式

`/app/output/terminology.tsv`，制表符分隔，表头固定：

```
source	translation	first_location	kind	note
```

| 字段 | 含义 | 要求 |
|---|---|---|
| `source` | 源语言术语（含缩写） | 原文拼写，大小写保持 |
| `translation` | 唯一译名 | 非空；全文只用这一种 |
| `first_location` | 首现位置 | `页N·段P3` 或 `摘要/正文/图注/结论` |
| `kind` | 类型 | `term`（术语）/ `abbr`（缩写）/ `proper`（专名）/ `formula`（公式符号） |
| `note` | 备注 | 候选译名、歧义说明、待人工确认 |

示例：

```
source	translation	first_location	kind	note
beamforming	波束成形	摘要	term	候选：波束形成（已锁定本译名）
SNR	信噪比	摘要	abbr	首现写全称 Signal-to-Noise Ratio（SNR）
```

## 抽取来源（按优先级）
1. 标题、摘要、关键词
2. 章节标题与正文首段
3. 图注、表头、公式符号
4. 结论与讨论

## 锁定 → 使用 → 回填 → 审计 循环

1. **抽取**：翻译前，从上述来源抽取术语与缩写，定唯一译名，写入表。
2. **锁定**：术语表一经建立即冻结；翻译中**只准用表内译名**。
3. **使用**：遇到术语，先在表内查；命中则用锁定译名，不命中则进入回填。
4. **回填**：新术语 → 定译名 → 追加一行（含 `first_location`）→ 再用；并回看已译段落，统一成该译名。
5. **审计**：译完后对每个术语检查全文各处译名是否一致（抽查标题/摘要/正文/图注/结论五处）；不一致处改为锁定译名，并在 `result.json.change_log` 记录"术语审计修正：X→Y（N 处）"。

## 缩写与专名规则
- 缩写首现处给全称 + 缩写，例如 `信噪比（SNR）`；之后仅用缩写。
- 专名（算法名、数据集名、系统名）保留原文，不译；首次出现可加译注。
- 公式符号保留原文符号，只译其文字定义。

## 验证口径（术语稳）
- 同一 `source` 的 `translation` 全文唯一；
- 无空译名、无重复条目（同一源词多译名是违规，除非在 `note` 标明"待人工确认"且正文只用其一）；
- 标题/摘要/正文/图注/结论五处译法抽查一致。
