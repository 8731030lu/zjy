# 术语表格式与锁定规则

## 术语表格式（TSV，写入 /app/output/terminology.tsv）

表头（制表符分隔）：

```
source_term	target_term	domain	first_occurrence	note
```

| 列 | 含义 | 要求 |
|---|---|---|
| source_term | 原文术语/缩写 | 一个源词一行，全篇唯一 |
| target_term | 锁定译名 | 全篇唯一；禁止同一源词两行不同译名 |
| domain | 领域标注 | 如 combustion / ML / materials / 通用 |
| first_occurrence | 首现位置 | 如 `页2 §2.1 正文` |
| note | 备注 | 如"保留原文""缩写：全称（译名）""行业标准译名""待人工确认" |

## 抽取来源（按优先级）

1. 标题、摘要、关键词
2. 各级章节标题
3. 正文高频实词、缩写、专有名词
4. 图注、表头、结论

## 锁定规则（先锁后用，全文一致）

- 术语表在**开始翻译前**冻结；翻译中遇到新术语，先回填术语表，再用锁定译名。
- 一个源词只允许一个译名。同一概念的不同写法（单复数、大小写、连字符变体）归并到同一行，避免两套译名。
- 缩写：首次出现写 `全称（缩写，译名）`，之后只写译名；缩写的译名与全称译名保持一致。
- 专有名词（人名、机构、软件、数据集、模型名）：采用通行译名；无通行译名则保留原文并注明。
- 数字、单位、变量符号、公式、文献编号**不进术语表、不翻译**。

## 术语一致性自检

翻译完成后，对每个锁定术语在**标题、摘要、正文、图注、结论**五处检索：
- 出现处是否都使用锁定译名？
- 是否出现临时改译/漏译/保留原文不一致？

发现不一致即修正，并在核验报告中记录。
